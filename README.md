# Rush Range

An **original** fast-paced, low-poly arcade first-person shooting range built in
**Godot 4.x** (GDScript, Forward+ / Jolt). Inspired by the *feel* of modern
Roblox-style FPS games, but every model, sound, texture and UI element here was
created from scratch for this project.

> All artwork is original and generated by scripts in `tools/`. No third-party
> or copyrighted assets are included.

## Play in the browser

**https://penguinlord7.github.io/rush-range/**

(Web export is single-threaded, so it runs on plain static hosting such as
GitHub Pages with no special headers.)

## Requirements

- **Godot 4.7** (stable) or newer 4.x
- Optional, only to regenerate assets:
  - **Blender 5.x** (headless)
  - **Python 3** (standard library only)

## Run

Open the folder in Godot and press **F5**, or from a terminal:

```bash
godot --path .            # runs res://scenes/main/main_menu.tscn
```

## Controls

| Input | Action |
|---|---|
| `W A S D` | Move |
| `Space` | Jump (`Space` again in mid-air = double jump, only with Fist equipped) |
| `Shift` | Sprint |
| `Ctrl` | Crouch |
| `Ctrl` while sprinting | Slide |
| `Left Mouse` | Fire / Punch / Throw (hold to charge grenade) |
| `Right Mouse` | Aim down sights |
| `R` | Reload |
| `1`–`4` | Switch weapon (Rifle / Handgun / Fist / Grenade) |
| `Mouse Wheel` | Cycle weapons |
| `Esc` | Pause / menu |
| `F5` | Restart run |

## Features

- Fast movement: walk, sprint (FOV kick + weapon lowered), crouch, momentum
  slide with cooldown, jump with air control.
- Four weapons with a shared, data-driven base class:
  - **Assault Rifle** – automatic, 30/120, sustained recoil climb, ADS.
  - **Handgun** – semi-auto, 12/60, big single-shot recoil, ADS.
  - **Fist** – short-range melee, no ammo, alternating hooks, and grants a
    **double jump** while equipped.
  - **Grenade** – hold to charge, physics projectile, timed explosion with
    radius falloff, regenerates slowly.
  - All weapons are held by original blocky first-person hands; the Fist is a
    simple cartoony two-prism mitt.
- Arcade recoil, movement-coupled spread (crouch = tighter, sprint/slide/air =
  looser), reloading, hit markers, floating damage numbers, muzzle flash,
  tracers, impacts, shell casings, explosions, footsteps.
- Five range areas: basic 10/25/50 m lanes, a movement course, moving targets,
  a random pop-up reaction test and a grenade pit.
- Main menu, settings (sensitivity, FOV, three volume buses, crosshair
  size/gap/thickness/dot, invert Y, screen-shake toggle), controls screen and a
  pause menu.

## Project layout

```
res://
├── scenes/        # main, player, weapons, targets, environment, ui
├── scripts/       # player, weapons, targets, systems, ui, main, test
├── models/        # original low-poly .glb (weapons, player, environment)
├── textures/ui/   # original SVG weapon icons
├── materials/     # (placeholder for future material resources)
├── audio/         # original synthesized .wav
├── animations/    # (procedural animation lives in the weapon/player scripts)
├── tools/         # asset generators + tests (not shipped in gameplay)
└── project.godot
```

### Autoloads (singletons)

| Name | File | Responsibility |
|---|---|---|
| `AudioManager` | `scripts/systems/audio_manager.gd` | Buses + pooled SFX playback |
| `Events` | `scripts/systems/events.gd` | Signal bus (hits, ammo, score, …) |
| `Settings` | `scripts/systems/settings.gd` | Persisted user settings |
| `GameState` | `scripts/systems/game_state.gd` | Session score / accuracy |
| `Fx` | `scripts/systems/fx.gd` | Pooled visual effects |

## How to modify

- **Weapon stats** – edit the exported values at the top of
  `scenes/weapons/<weapon>.tscn`. Damage, RPM, magazine, recoil, spread, ADS FOV,
  reload time, fire sound and mount offsets are all exported. Add a new weapon
  by copying a scene + script and adding it to `WeaponManager.WEAPON_SCENES`.
- **Movement feel** – all tuned on the `Player` node in
  `scenes/player/player.tscn` and the exports in `scripts/player/player.gd`.
- **Camera feel** – `scripts/player/player_camera.gd` (bob, recoil recovery,
  FOV, landing, shake).
- **Targets** – `scenes/targets/*.tscn`; behaviour is set per instance in
  `scripts/systems/arena.gd` (`NONE`, `HORIZONTAL`, `VERTICAL`, `POPUP`).
- **Map** – edit the `_area_*` functions in `scripts/systems/arena.gd`. Each
  prop/target is one line of data.
- **Input** – actions are defined in `project.godot`; regenerate with
  `godot --headless --path . --script res://tools/setup_input.gd`.

## Regenerating assets

```bash
# Models (writes models/**/*.glb)
blender --background --factory-startup --python tools/blender/build_models.py

# Sounds (writes audio/**/*.wav)
python3 tools/audio/gen_sounds.py
```

## Tests / tooling

```bash
# Unit-ish checks: player, weapons, ammo, reload, damage, respawn
godot --headless --path . res://tools/smoke_test.tscn --quit-after 900

# Gameplay checks: movement, sprint, slide, jump, fist, grenade, settings, menu
godot --headless --path . res://tools/play_test.tscn --quit-after 5000

# Capture verification screenshots to res://screenshots (needs a display)
godot --path . res://tools/screenshot.tscn
```

Both test scenes print `PASS`/`FAIL` lines and exit non-zero on failure.

## Web export / hosting

The `export_presets.cfg` includes a single-threaded **Web** preset (required for
GitHub Pages, which cannot send the COOP/COEP headers threaded builds need):

```bash
godot --headless --path . --export-release "Web" build/web/index.html
```

Export templates for the engine version must be installed (download
`Godot_v4.7.2-stable_export_templates.tpz`, extract the `templates/web_*` files
to `~/.local/share/godot/export_templates/4.7.2.stable/`).

To publish, the built files are pushed to the `gh-pages` branch and Pages is
served from that branch root (`/`). The site is fully static: `index.html`,
`index.js`, `index.wasm`, `index.pck`.
