# Rush Range — Design Spec

Date: 2026-09-27
Status: Implemented

## Goal

A complete, playable, **original** first-person 3D shooting range in Godot 4.x
that recreates the *feel* of fast-paced Roblox-style arcade shooters without
copying any copyrighted work. Emphasis on game feel: movement, aiming, shooting,
weapon switching, recoil and hit feedback.

## Constraints & decisions

- **Engine:** Godot 4.7, GDScript, Forward+, Jolt physics.
- **Input:** keyboard + mouse; actions stored in `project.godot` and generated by
  `tools/setup_input.gd`.
- **Models:** original low-poly `.glb` generated headlessly in Blender
  (`tools/blender/build_models.py`).
- **Audio:** original synthesized 16-bit mono WAVs
  (`tools/audio/gen_sounds.py`).
- **Animation:** procedural, in code (weapon sway/bob/kick/ADS/reload/equip,
  punch and throw), avoiding authored skeletal clips.
- **No gore, no multiplayer, no campaign.** Exactly four weapons.

## Architecture

- **Autoloads:** `AudioManager`, `Events` (signal bus), `Settings` (persisted),
  `GameState`, `Fx` (pooled effects). UI and gameplay communicate through
  `Events` to stay decoupled.
- **Player:** `CharacterBody3D` with an explicit movement state machine
  (WALK/SPRINT/CROUCH/SLIDE/AIR); `player_camera.gd` owns look, clamp, bob,
  landing dip, recoil offsets, shake and FOV.
- **Weapons:** `WeaponBase` (stats + fire/reload/recoil/spread + procedural
  animation) with subclasses `AssaultRifle`, `Handgun`, `Fist`, `Grenade`.
  `WeaponManager` owns spawning, slots, switching, ADS and input.
- **Damage:** `RangeTarget` health with `TargetHitbox` children (body/head
  multipliers); guns use hitscan rays, the fist a sphere cast, grenades a
  radius query with falloff. Death → flash, burst, score, respawn.
- **Arena:** data-driven build in `arena.gd` (floors/walls/slopes from primitives
  for reliable collision, Blender modules for visuals; targets configured per
  instance).
- **UI:** main menu, settings panel, controls panel, pause menu, HUD (dynamic
  crosshair, weapon icon, `cur / reserve`, reload indicator, hit markers,
  score, notices).
